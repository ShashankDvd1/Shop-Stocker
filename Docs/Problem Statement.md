# Problem Statement

## Context

You've recently opened a new **Amul outlet store** selling dairy products. All sales and stock tracking is currently manual — sales are written in a notebook, and there's no system tracking inventory, purchases, or profitability.

## Core Problem

There is **no reliable, centralized system** to record daily sales, track live stock levels, log new inventory, and calculate profit — resulting in guesswork around what's selling, what's running low, and how much money the store is actually making.

## Pain Points

| # | Issue | Root Cause |
|---|-------|------------|
| 1 | Manual notebook entry for every sale | No structured logging system |
| 2 | No visibility into remaining stock | Purchases and sales aren't netted against each other anywhere |
| 3 | No daily sales/product-level breakdown | Data isn't aggregated or summarized |
| 4 | New stock isn't reflected in inventory | No link between restocking and stock counts |
| 5 | Daily/monthly profit and earnings unknown | No cost vs. revenue calculation exists at all |

## Goal

Replace the notebook with **one simple, self-calculating system** that any non-technical person can use daily — log a sale or a restock in seconds, and have stock levels, daily sales, and profit update automatically.
